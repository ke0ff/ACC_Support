FF-CAD, GEN-II, ACC Version
Mounting Hardware 3D models

This folder contains 3D CAD files for the FF-CAD mounting hardware.  There are two versions: RC-96 and RC-85.

The RC-96 mounting features two off-the-shelf standoffs and a 3D printed "offset" standoff for 0.5" mounting height.

RC-96 offset standoff: ostoff.stl
RC-96 standoff: stoff.stl (used for the RC-85 chassis version)

The RC-85 version features two (2) F-F standoffs, one (1) offset-standoff, and one (1) "cap" to allow one of the F-F standoffs to "grip" the RC-85 PCB edge.

RC-85 offset standoff: ostoff85.stl
RC-85 standoff: stoff85.stl
RC-85 bottom cap: cap85.stl

The RC-96 version attaches directly to the RC-96 U6 socket.  No "spacer" sockets are needed.

The RC-85 chassis version also attaches directly using the RC-96 M-F standoff and f-f standoff.

For the board-only RC-85, three spacer DIP sockets are used to raise the delay above the J8 connector.  The longer standoffs (one features a 4-40 stud to turn it into a M-F standoff) and end cap are used.
