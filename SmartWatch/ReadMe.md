Design files for the DS1216E (AKA DS1315 chip) smartwatch module clones.

Included are two battery holder designs which interface with the DS1216E clone.  One is targeted at the RC85 controller, while the other is suited for the RC96.

Note that some RC85 PCBs have an unused VROM socket that would allow them to utilize the RC-96 battery (the RC-96 battery is lower profile than the RC-85 version).
