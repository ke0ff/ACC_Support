# ACC_Support
ACC Repeater controller support repo

FC900_PLDEC: An interposer for the FC-900 to provide CTCSS decode capability to the link stack
FFCAD_FOLDER: GEN2 Audio Delay with ACC compatability
PhakePAL_RC96: Logic interposer to replicate the RC-96 address decoder PAL with available, SMD parts
RC96 Front Panel: Front Panel Clone (including reset and DTMF keypad) for the RC-96
RC96_CTCSS: Clone of the RC-96 Tone Panel PCB
RC85x..x: Various EPROM/EEPROM Image files for the RC-85
