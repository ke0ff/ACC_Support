# ACC_Support
ACC Repeater controller support repo</br>
</br>
<b>FC900_PLDEC:</b> An interposer for the FC-900 to provide CTCSS decode capability to the link stack</br>
<b>FFCAD_FOLDER:</b> GEN2 Audio Delay with ACC compatability</br>
<b>PhakePAL_RC96:</b> Logic interposer to replicate the RC-96 address decoder PAL with available, SMD parts</br>
<b>RC96 Front Panel:</b> Front Panel Clone (including reset and DTMF keypad) for the RC-96</br>
<b>RC96_CTCSS:</b> Clone of the RC-96 Tone Panel PCB</br>
<b>RC85x..x:</b> Various EPROM/EEPROM Image files for the RC-85</br>
