PhakePAL Interposer design for the RC-96 Controller
Uses SMD logic ICs to replicate the PAL functionality extracted from a factory programmed PAL.
Interposer Consists of a 20-pin DIP header, the PCB described herein, and the SMD components
indicated in the schematic.

Design files are in CircuitStudio (A.K.A. Altium lite).  Gerber and NC Drill files are under
the "Default Configuration" folder path.
